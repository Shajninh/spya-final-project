## Project Description
This repository contains a modern, responsive web application prototype for the **South Parkland Youth Association (SPYA)**. Built on top of the Bootstrap 5 Mentor template, the site provides local families, players, and coaches with clear access to youth sports programs, registration details, schedules, and association information in the Parkland/Allentown area.

---

## Major Pages & Features Currently Implemented
* **Home Page (`index.html`):** Overview of SPYA, hero banner, call-to-action for registration, and key stats.
* **About Us (`about.html`):** History, mission statement, volunteer core values, and organized cards highlighting all 8 sports offered.
* **Sports Programs (`sports.html`):** Detailed breakdown of seasonal programs (Baseball/Softball, Basketball, Football/Flag, Soccer, Cheerleading, Field Hockey, Lacrosse).
* **Events & Schedules (`events.html`):** Calendar/list layout for upcoming sports registration deadlines and community events.
* **Contact (`contact.html`):** Outreach form and general association contact information.

## Instructions for Running the Prototype

### Option 1: View Locally in Browser
1. Clone the repository:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/SPYA-Project-1.git

2. Navigate into the project folder:
    cd SPYA-Project-1/Mentor

3. Double-click index.html or open it directly in any web browser (Chrome, Safari, Firefox).

### Option 2: Live Server (VS Code Extension)
Open the project folder in Visual Studio Code.
Install the Live Server extension (if not already installed).
Right-click index.html and select "Open with Live Server".
